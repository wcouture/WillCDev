ServiceAttribute
Marks a concrete class as a dependency-injection service. Stores the interface it implements and its lifetime (Scoped or Singleton). Discovered at startup by ServiceRegistrationExtensions.
System.Attribute→ServiceAttribute
📋 Declaration
